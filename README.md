# auto-tools

Windows Forms 前台循环工具，沿用 Windows 自带的 .NET Framework、管理员启动方式和像素风格界面。构建产物为 `dist/auto-tools.exe`，字体、图标和许可证已内嵌，无需单独安装其他运行时或字体（系统需已有 .NET Framework 4.5 或更高版本）。

本次聊天选项版本单独构建为 `dist/auto-tools-chat-option.exe`，发行包为 `dist/auto-tools-20261110-chat-option.zip`；解压后运行包内的 `auto-tools.exe`。

项目由相邻 `auto-box` 的现有源码迁入，在本目录实现鼠标取点及循环功能；原 `auto-box` 未修改。原实施计划见 `MOUSE_AUTOMATION_PLAN.md`，以下行为包含用户随后指定的循环次数和“赌增幅强化”流程。

## 模式与循环次数

| 模式 | 完整一轮 |
| --- | --- |
| 赛利亚盒子模式 | 所选主键盘数字 1–6 → 空格 |
| 双击空格模式 | 所选主键盘数字 1–6 → 空格 → 空格 |
| 赌增幅强化 | 固定主键盘数字 1 → 已取点位置的左键单击 → 回车 → 回车；勾选聊天选项时再追加一次回车 |

三个模式都支持：

- 勾选“一直循环”：持续运行，直到主动停止或出现输入错误。
- 取消勾选：输入 1–1,000,000,000 次，完成指定次数后自动停止。
- 状态栏显示已完成次数；暂停和等待条件恢复不消耗次数。一次完整动作序列结束后才计为一轮，停止时未完成的序列不计数。
- 最后一轮结束后立即完成，不再等待下一轮的间隔。

两个键盘模式保持原有固定时间：按住 10 ms，数字键松开到第一次空格间隔 50 ms，两个空格之间间隔 50 ms，完整一轮结束到下一轮等待 60 ms。数字操作键仅支持主键盘 1–6，不是小键盘。

## 赌增幅强化

1. 运行 `dist/auto-tools.exe`，接受管理员权限提示，选择目标游戏窗口。
2. 在模式下拉框选择“赌增幅强化”。此模式固定按数字 1，隐藏其他数字操作键选项。
3. 在游戏设置中优先选择窗口模式和需要的分辨率。在工具里输入**客户区**宽高，点击“检查尺寸”。客户区不包含标准标题栏和边框；游戏画面留黑也算在客户区内。
4. 必要时主动点击“应用尺寸”。程序保留窗口位置，调整后重新读取实际客户区尺寸；游戏拒绝或自行恢复尺寸时会显示实际值并阻止开始。
5. 点击“开始取点”，切回所选游戏，将鼠标移到目标按钮，按默认 **F7**。失败会说明原因并保留旧坐标，可以重试或取消取点；取点过程不发送输入。
6. 设置“下轮等待 ms”，范围 **0–3,600,000 ms**，默认 **1000 ms**。这段时间从最后一次回车松开后开始计算。已保存的自定义等待时间继续保留。
7. “增幅后出现聊天了勾选我”默认不勾选，每轮按两次回车；勾选后每轮按三次回车，第二次到第三次间隔 50 ms。选项会保存，运行中锁定。
8. 选择“一直循环”或指定次数，切回游戏按 **F8** 开始。

每轮具体顺序：

```text
数字 1 按下、松开
→ 等待 100 ms
→ 将鼠标移到已取点位置，左键按下、松开
→ 等待 50 ms
→ 回车按下、松开
→ 等待 150 ms
→ 回车按下、松开
→ 如勾选“增幅后出现聊天了勾选我”，等待 50 ms 再按下、松开第三次回车
→ 完成次数 +1
→ 如需下一轮，等待用户设置的毫秒数
```

每个按键及左键默认按住 10 ms。数字 1 到左键的间隔为 100 ms，左键到第一次回车为 50 ms，第一次到第二次回车为 150 ms。仅勾选聊天选项时，第二次回车松开后再等 50 ms 按第三次回车。间隔均从上一个动作松开算到下一个动作按下；Windows 调度、鼠标定位与条件检查会带来额外耗时。

**自动点击会移动真实系统鼠标。** 保存的是客户区相对坐标，每次点击重新调用 Windows 坐标转换接口。只移动窗口且客户区尺寸不变时无需重新取点；尺寸变化时暂停输入，恢复原尺寸后可继续，也可停止后重新取点。不会按比例缩放旧坐标。

取点、移动和每次按下前均检查目标窗口、焦点、客户区尺寸与目标点遮挡。鼠标移动后还会重新确认光标和窗口位置；用户正按着左键时等待其松开。检查与发送之间仍存在很短的竞争窗口，不能保证游戏必然响应模拟输入。

切换目标窗口、窗口重建或重启工具后，旧点位必须重新采集，或点击“确认已存点位”明确绑定到当前同进程名、同客户区尺寸的窗口。确认按钮无法判断游戏内按钮布局是否变化，需要用户核对。

## 控制与状态

- 默认 **F8** 开始 / 停止，**F9** 停止，**F10** 手动暂停 / 继续；赌增幅强化另有默认 **F7** 取点。可选择 F1–F12，检查重复和系统占用。
- 切出游戏自动暂停，切回继续当前尚未完成的动作序列。手动暂停需要主动恢复。
- 最小化进入托盘，双击托盘图标恢复，托盘菜单支持开始、停止、暂停和退出。
- 停止或关闭会取消等待并尝试释放本工具按下的键和左键。释放失败会显示错误、保留记录并禁止开始新的循环，可按“停止”重试；关闭期间出现释放错误会保留窗口显示原因。
- 窗口关闭或身份变化时终止，需要刷新、重新选择和确认点位。
- 尺寸不符、点位被覆盖、未在前台时暂停。输入发送失败时停止并报告，释放失败同时发生时保留两者原因。
- 程序不会自动开始循环，也不会主动激活游戏。

现有清单保持系统 DPI 感知。首版只接受所有显示器缩放与程序系统 DPI 一致、目标窗口 DPI 一致的场景；混合 DPI、运行中更改缩放或无法验证的旧系统多屏配置会明确阻止操作。负坐标副屏使用整个虚拟桌面归一化；虚拟桌面单轴超过 65,536 像素时阻止执行。

## 设置与兼容

配置写入 `%LOCALAPPDATA%\AutoTools\settings.xml`。新配置不存在时，兼容读取 `%LOCALAPPDATA%\AutoBox\settings.xml`，之后保存到新位置，保留旧文件。

保存模式、数字操作键、控制快捷键、是否一直循环、指定次数，以及取点坐标、采集尺寸、期望尺寸、取点快捷键、下轮等待时间、取点进程名和聊天选项。`(0, 0)` 是有效点位，单独保存是否已取点的标记。原模式编号 0、1 保持不变，赌增幅强化使用编号 2。旧配置默认一直循环、未取点、聊天选项不勾选，下一次启动只恢复选项。

## 构建与逻辑验证

在本项目目录用 Windows PowerShell 运行，不需要安装 .NET SDK：

```powershell
.\build.ps1
.\build.ps1 -Test
.\build.ps1 -Test -TestPlatform x86
```

`build.cmd` 也可传入相同参数。默认输出 `dist/auto-tools.exe`。旧 EXE 被占用时可使用 `-OutputName auto-tools-new.exe`，不必终止正在运行的程序。

`-Test` 只运行模拟后端的逻辑测试，不创建实际窗口，不注册全局快捷键，不发送真实键盘或鼠标输入。覆盖原有键盘循环，以及完整强化序列、100 / 50 / 150 ms 间隔、下轮等待、有限次数、坐标重新换算、边界、焦点竞争、遮挡、暂停恢复、取消、释放异常、DPI 拒绝、配置兼容和当前进程位数的原生 INPUT 结构布局。

保留了原项目的窗口身份与 UI 预览检查，只有显式运行 `-InteractiveTest` 才会执行；本次未执行。Windows 窗口尺寸、系统鼠标、真实游戏响应、多屏和 DPI 的实际验收由用户进行。执行结果见 `TEST_REPORT.md`。

UI 来源和许可见 `third_party/README.md`。
